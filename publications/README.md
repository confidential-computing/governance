# CCC Publications

This directory contains publications owned by the Technical Advisory Council (TAC).
Publications owned by a Special Interest Group are kept with that SIG, for example
[GRC governance patterns](../SIGs/GRC/publications/).

Where a document's figures were authored in a presentation tool, the source file is
kept alongside the document so the images can be maintained.
